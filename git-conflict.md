   # Описание разрешения конфликта

   ## Где возник
   В файле `README.md` при слиянии `feature/cart` в `main`.

   ## Причина
   В обеих ветках была изменена вторая строка описания проекта, но с разным текстом. Git не смог выбрать версию автоматически.

   ## Как исправлен
   1. Открыл файл в редакторе через GitHub Desktop.
   2. Удалил служебные маркеры `<<<<<<<`, `=======`, `>>>>>>>`.
   3. Объединил текст в одну строку: "Описание: Мини-магазин с фокусом на каталог и корзину."
   4. Сохранил файл и нажал "Commit merge" в GitHub Desktop.
